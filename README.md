# Kotor Shader Inject


### Effects
#### SMAA
Enhanced Subpixel Morphological Antialiasing
An Alternative Anti Aliasing to the games MSAA.
#### Depth of Field
Adds depth of field during dialogue.
#### Filmic Grain
Adds a film gran effect.
#### SSAO
Screen space ambient occlusion. Adds subtle shadows around objects to improve lighting.
#### Vignette
Adds a subtle vignette effect.
#### Subtle Force Speed Effect
Keeps the original force speed blur effect but limited to the edges of the screen.


### Usage
- Use with Kotor Patch Manager: https://github.com/LaneDibello/Kotor-Patch-Manager
- Subtle Force Speed Effect for K1 requires: https://codeberg.org/Synchro/kotor-modern-driver-compatibility
- Enable ShaderInject patches adn click launch.
